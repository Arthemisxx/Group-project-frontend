# Photo Spots App

A web application for searching and sharing photography locations. The project allows users to browse a map of points (spots) and add new locations to a shared database.

This repository contains the frontend part of the application, developed as a university group project. The user interface is built using React, TypeScript, and the Vite build tool.

The backend service for this application is available in a separate repository: [photo_group_project](https://github.com/taramachuk/photo_group_project).
### Requirements
* Node.js
* npm package manager

### Setup Instructions

1. Clone the repository:
`git clone https://github.com/Arthemisxx/Photo-Spots-App-Front.git`

2. Navigate to the project directory:
`cd Photo-Spots-App-Front`

3. Install all necessary dependencies:
`npm install`

4. Start the development server:
`npm run dev`

The application will be accessible in your web browser. The local address will be displayed in your terminal once the server starts successfully.
